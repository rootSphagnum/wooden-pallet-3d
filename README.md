# Wooden Pallet — 3D Model

A simple wooden pallet 3D model created in Blender 4.0.

**Author:** Sphagnum

## Preview

![Pallet preview 1](screenshots/photo1.jpg)

![Pallet preview 2](screenshots/photo2.jpg)

## Files

- `model/pallet.blend` — editable Blender source file.
- `model/pallet.obj` — exported geometry.
- `model/pallet.mtl` — material definitions used by the OBJ file.
- `screenshots/` — preview images.

When importing the OBJ, keep `pallet.obj` and `pallet.mtl` in the same folder.
